Typst, without the friction of a general-purpose IDE

Typst is a modern typesetting compiler, much faster than LaTeX and without its arcane syntax — but it still required a terminal and any old text editor to use. DBV Typst Editor bundles the official Typst compiler inside the app itself (Rust + Tauri v2, no Electron) and adds what a real academic document needs: templates with a data form, citation and image assistants, and a preview that updates on its own as you type.

None of this locks you in: the project you create is an ordinary Typst directory, which compiles just as well from the terminal with the official CLI. If you ever stop using DBV Typst Editor, your document is still yours.

An AI assistant of your choice, that never writes without you seeing it

It is optional: with none connected, the editor works exactly as it always has. With a local AI, nothing leaves your computer.

🔌

Connect a local or cloud AI

Local (Ollama, LM Studio, llama.cpp, any OpenAI-compatible server) or cloud with your API key (Anthropic, OpenAI, Gemini, OpenRouter). "Connect an AI" detects what is already on your computer.

🤖

Use your subscription & pick models

Connect Claude Code, Codex, Gemini CLI, Copilot, or Antigravity from the tripartite AI modal, tune model and reasoning effort, and approve every edit with its diff.

✅

It proposes, compiles, and you decide

The AI proposes changes, across several files if needed. DBV compiles them in memory and tells you whether they compile before showing them to you; you accept or reject each hunk and can always undo.

🔒

Privacy by design

With a local AI nothing leaves your computer. In the cloud you are asked before the project is sent. Keys go to the system credential store, never to a file.

🎯

You control the context

You see what is sent: the open file, the selection, problems, outline, files mentioned with @ and the preview page. You can remove any item.

✍️

Inline AI and "Explain and fix"

Ctrl+Shift+I on a selection: improve, fix, translate, shorten, convert to a table or list. In Problems, "Explain and fix" solves an error with an already-checked proposal.

📚

Offline Typst documentation

The official documentation for the exact compiler version ships with the app, with a search that also understands Spanish terms. The AI looks things up in it instead of inventing functions.

🔎

Works with Typst Universe for real

It searches real templates and packages in the catalog and reads how they are used; it never writes a name or version from memory. With the AI’s help, or without it, you can move a document you already have into IEEE, Springer or whatever format you choose.

👁️

Sees the result and fixes what is missing

With a model that accepts images, the AI looks at the rendered pages to judge the layout. If a typeface is missing it offers it (with its licence) and adds it to the project only if you confirm.

🔌

MCP server for your other agents

Claude Code, Cursor, Codex or Claude Desktop can use DBV’s exact compiler, see the pages and query Universe. Read-only, no network and confined to the project; installing a package always asks you first.

🧮

Problems and data at hand

A Problems panel with every error in the project and a CSV/TSV data viewer with "Insert as table".
